# Fantasy Hockey Analytics

A personal, non-commercial fantasy hockey analytics and roster decision-support project.

## Purpose

This project uses data from my personal Yahoo Fantasy Hockey league to support fantasy hockey analysis, including:

- Roster analysis and optimization
- Waiver-wire and free-agent evaluation
- Player comparisons
- Trade analysis
- Matchup analysis
- League-specific fantasy scoring analysis

The application is intended for personal, single-user use. It accesses only fantasy leagues associated with my own Yahoo account.

## Yahoo Fantasy Sports API

Yahoo Fantasy Sports API access is used to retrieve relevant league information, including league settings, rosters, available players, player statistics, standings, matchups, and transaction information.

Yahoo Fantasy Sports data retrieved by this project is used for personal analysis and is not redistributed or offered as a commercial data service.
